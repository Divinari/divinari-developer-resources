# Contributing to `divinari-developer-resources`

Contributions to public schemas, validator rules, documentation, and synthetic test fixtures are welcome!

## Rules

1. **Zero Proprietary Internals:** Never submit credentials, Firebase config, client/server code from the proprietary Divinari platform, encrypted payload internals, or third-party copyrighted content.
2. **Pass Local Validation:** Run `pytest -q validator/tests/` and verify all valid/invalid schema fixtures cleanly.
3. **Apache 2.0 + DCO 1.1:** Contributions are submitted under the Apache License, Version 2.0 (Section 5) and require `Signed-off-by: Your Name <you@example.org>` (`git commit -s`) certifying Developer Certificate of Origin v1.1 compliance.
