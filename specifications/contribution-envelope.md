# Provenance, License & Attribution Envelope

Every public dataset submitted to Divinari open repositories MUST declare explicit origin and license rights upfront:

| Field | Permitted Public Values | Purpose |
|---|---|---|
| `license` | `CC-BY-4.0`, `CC0-1.0` | Ensures downstream educational and open preservation compatibility |
| `origin_type` | `native_speaker`, `public_domain`, `cc_by_4_0`, `maintainer_scaffold` | Audits human authorship vs. open third-party origin |
| `source_citation` | Non-empty provenance string | Names human source context, public-domain edition year, or upstream CC BY URL |
| `contributors` / `attribution` | Handle or display name(s) | Enables accurate credit in `ATTRIBUTION` / `CONTRIBUTORS.md` |
