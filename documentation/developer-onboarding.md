# Developer Onboarding

1. Clone `divinari-developer-resources` locally.
2. Create a Python 3.10+ virtual environment and install `validator/requirements.txt`.
3. Run `pytest -q validator/tests/` to verify schemas and fixtures cleanly.
4. Read [Schema Versioning Policy](./schema-versioning-policy.md) and [Terminology Glossary](./terminology-glossary.md) before proposing schema updates.
