# Terminology Glossary

- **Concept Key (`concept_key`):** Canonical cross-linguistic semantic anchor (`GREETING_MORNING`).
- **Sense Key (`sense_key`):** Unique sense identifier disambiguating polysemous headwords.
- **Normalized Span:** Half-open character slice `[char_start, char_end)` matching Unicode NFC `sentence_text`.
- **Air-Gapped Ingestion:** Manual maintainer review and batch import from tagged public repository releases into private Divinari build tools (no CI webhook auto-deploy).
