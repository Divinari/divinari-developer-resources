# Code of Conduct

This repository follows the shared pluralistic Divinari Community Code of Conduct: respectful collaboration regardless of language background, ethnicity, faith tradition or secular worldview, or technical background, alongside strict honesty regarding source licensing and provenance.

Report issues confidentially to **support@divinari.app** (subject: `Code of Conduct Report`).

*Adapted from Contributor Covenant v2.1 (<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>).*
